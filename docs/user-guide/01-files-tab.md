# Chapter 1: Files & Project Management

The **Files Tab** in TRACE (`tab_files.py`) is the entry point for importing raw patient motion data, managing analytical waveform presets, and selecting output directories for generated G-code files.

---

## Files Tab Overview

When you open the **Files** tab, you will find:

- **Project Directory Selector**: Choose where motion data and G-code outputs are saved.
- **Raw Data Import Panel**: Load CSV, TSV, DICOM, or log files containing respiratory motion traces.
- **Preset Library**: Select pre-defined standard motion templates (e.g., standard sinusoidal breathing, irregular breathing, high-frequency motion).

---

## 1. Importing Patient Respiratory Curves

TRACE supports importing patient-derived motion profiles captured by clinical motion tracking systems (such as RPM, Anzai, or Varian RGSC).

### Supported File Formats

| Format | Extensions | Description |
| :--- | :--- | :--- |
| **CSV / TSV** | `.csv`, `.tsv`, `.txt` | Columnar data containing time vs displacement columns. |
| **RPM Logs** | `.vms`, `.txt` | Varian Real-Time Position Management log files. |
| **G-code** | `.gcode`, `.g` | Pre-compiled Duet G-code trajectory files. |

### Step-by-Step Import Procedure

1. Click **Browse File** under the *Import Motion Data* panel.
2. Select your raw motion file.
3. Specify the time column index and motion axis column index.
4. Click **Parse File**. TRACE will render a preview plot of the imported waveform.

---

## 2. Managing Project Directory & Outputs

Outputs generated by TRACE (such as compiled `.gcode` files and trajectory logs) are stored in the selected Project Directory.

- **Set Default Directory**: Use **Select Directory** to choose your target folder.
- **File Naming Convention**:
    ```text
    <project_name>_<axis>_<waveform_type>.gcode
    ```
    *Example*: `planned_motion_platform_SI_sin.gcode`

!!! tip "Organizing Patient Datasets"
    We recommend creating a separate subfolder for each patient or phantom study inside your project directory to keep G-code and verification logs organized.
